# Interface Segregation Principle - ISP

Este projeto apresenta uma solução simples para a situação-problema sobre o princípio **Interface Segregation Principle (ISP)**, um dos princípios do SOLID.

O objetivo é mostrar que uma classe não deve ser obrigada a implementar métodos que não utiliza. Para isso, o exemplo separa responsabilidades em interfaces menores e mais específicas, deixando o código mais organizado, flexível e fácil de manter.

## Tecnologias utilizadas

* Java
* Programação Orientada a Objetos
* Princípios SOLID

## Objetivo

Demonstrar, de forma prática, como aplicar o princípio da segregação de interfaces em Java, evitando interfaces grandes demais e melhorando a estrutura do código.
