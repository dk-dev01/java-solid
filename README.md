# Java SOLID

Este repositório reúne exemplos simples e práticos dos princípios **SOLID** aplicados em Java.

O objetivo principal é registrar meus estudos sobre orientação a objetos e boas práticas de desenvolvimento, revisando conceitos que estudei com mais profundidade durante a faculdade e organizando exemplos para consulta e evolução no GitHub.

## Sobre o projeto

O projeto foi desenvolvido com foco em exemplos didáticos, separando cada princípio do SOLID em uma pasta própria. A ideia não é criar um sistema completo, mas sim demonstrar, de forma simples, como cada princípio pode ser aplicado no código.

## Princípios abordados

### S — Single Responsibility Principle

Princípio da Responsabilidade Única.

Uma classe deve ter apenas um motivo para mudar, ou seja, deve possuir uma responsabilidade bem definida.

### O — Open/Closed Principle

Princípio Aberto/Fechado.

Uma classe deve estar aberta para extensão, mas fechada para modificação. Isso permite adicionar novos comportamentos sem alterar diretamente o código já existente.

### L — Liskov Substitution Principle

Princípio da Substituição de Liskov.

Classes derivadas devem poder substituir suas classes base sem quebrar o funcionamento do programa.

### I — Interface Segregation Principle

Princípio da Segregação de Interfaces.

Uma classe não deve ser obrigada a implementar métodos que não utiliza. O ideal é dividir interfaces grandes em interfaces menores e mais específicas.

### D — Dependency Inversion Principle

Princípio da Inversão de Dependência.

Módulos de alto nível não devem depender diretamente de módulos de baixo nível. Ambos devem depender de abstrações.
